Setup

Backroad needs a free GraphHopper routing key. Sign up at graphhopper.com, open the dashboard and copy your API key in. It stays on this phone.

Tap anywhere on the map to start the loop somewhere other than your current position. Road measurements are reused while you stay in one area, so only the first search of the day is slow. Each candidate costs one routing credit.
